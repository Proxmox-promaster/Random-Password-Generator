# Random Password Generator
**Автор:** Влад Чигодайкин
**Вариант:** Random Password Generator (Генератор случайных паролей)

## Описание программы
Это графическое приложение (GUI) на языке Python, которое позволяет создавать безопасные случайные пароли. Пользователь может гибко настраивать параметры генерации и видеть историю последних созданных паролей.

### Основные функции:
- Выбор длины пароля через ползунок (от 4 до 32 символов).
- Выбор типов символов: заглавные буквы, цифры, специальные знаки.
- Просмотр истории (хранит последние 10 паролей).
- Автоматическое сохранение истории в файл `history.json`.

## Инструкция по запуску

### 1. Требования
Для работы программы необходим установленный интерпретатор **Python 3.x**. 
Дополнительные библиотеки не требуются (используется встроенный модуль `tkinter`).

### 2. Как запустить
1. Скачайте файл с кодом (например, `main.py`).
2. Откройте терминал или командную строку в папке с файлом.
3. Запустите программу командой:
   ```bash
   python main.py
   ```

## Примеры использования

1. **Генерация простого пароля:**
   - Выберите длину: 8.
   - Оставьте галочку только на "Цифры".
   - Нажмите "Сгенерировать".
   - Результат в поле ввода: `58291034`.

2. **Генерация сложного пароля:**
   - Выберите длину: 16.
   - Отметьте все чекбоксы (Заглавные, Цифры, Спецсимволы).
   - Нажмите "Сгенерировать".
   - Результат: `G7#sP2!kL9@mQ5*z`.

3. **История:**
   - Все созданные пароли отображаются в нижнем списке. Последний пароль всегда будет сверху.
